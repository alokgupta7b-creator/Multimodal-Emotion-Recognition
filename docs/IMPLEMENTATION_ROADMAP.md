# Implementation Roadmap

1. Stabilize dependencies, paths, preprocessing, serialization and tests.
2. Benchmark and improve the existing text and speech baselines.
3. Add a separately evaluated facial emotion pipeline.
4. Add sample/timestamp alignment and missing-modality handling.
5. Implement and evaluate reliability-aware fusion.
6. Add offline inference APIs, then real-time APIs.
7. Add deployment, monitoring, privacy and performance validation.

Each phase must report executed tests and measured results. No model accuracy
may be reported unless the corresponding training or evaluation was run.
